Put your photos in this folder (web/public/images). Use these names.
.jpg, .jpeg, .png, .webp and .avif all work.

hero.jpg / hero.png
             App screenshot at the top of the home page (phone or tablet).
             hero.png is already in place. Replace this file to update the hero.
             Without it, the page shows a drawn tablet with the app.
how-1.jpg    "Auria in real life" - at home (stock photo from Pexels; replace with your own anytime)
how-2.jpg    "Auria in real life" - at school
how-3.jpg    "Auria in real life" - outside
video.jpg    Cover picture for the video (optional).

In development (npm run dev) missing photos show an empty frame with the file name.
In the published site (npm run build) missing photos are simply left out.

After adding photos: refresh the page in dev, or run "npm run build" again for the live site.
