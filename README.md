# Khidi — marketing site

Next.js static site (Georgian `/`, English `/en/`).

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production config

Edit `src/config/site.ts` (domain, store links, YouTube id).

## GitHub Pages

After push to `main`, enable **Settings → Pages → Build and deployment → Source: GitHub Actions**.

Live URL: [https://schita01.github.io/auth1/](https://schita01.github.io/auth1/)
